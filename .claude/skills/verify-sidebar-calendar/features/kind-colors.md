# Kind colors and settings

The kinds are the H1 headings of the core Daily notes template. Each kind has an on/off switch and a color in Settings; an entry's bar and day-list swatch take its kind's color. A color is the theme accent (`""`), one of Obsidian's named colors (`red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple`, `pink`, drawn with `var(--color-<name>)` so they follow the light or dark theme), or a custom `#rrggbb`. The row's swatch opens a small popover of color dots; the dashed `+` opens the native color input only when clicked. Only kinds that are on and still in the template are read. Settings shows whether the template is linked, follows template edits (a new H1 becomes a kind with the next unused named color, a removed one is listed as not in the template with a delete button), and every change re-reads the daily notes at once.

## Sub-features

- `e-match` colors an entry with its kind's color (`업무` is `red`, drawn as the theme's `--color-red`).
- `e-accent` uses the theme accent for a kind with an empty color (`개인`).
- `e-status` shows the template status line and one row per kind in template order.
- `e-toggle` turns a kind off, which removes its bars at once and saves it; turning it on brings them back.
- `e-popover` opens the color popover from a row's swatch: nine dots with no text (theme accent, then the eight named colors), the current one ringed, each with a tooltip; picking one saves it and closes; Escape and an outside click close it without closing Settings.
- `e-theme` a named color follows the theme: the same `green` kind draws with the light theme's `--color-green`, then the dark theme's.
- `e-custom` the dashed `+` clicks a hidden `input[type=color]`, opened on the swatch's current color; the hex the user picks is saved and drawn.
- `e-template` follows a template edit: a new H1 becomes an enabled kind with the first unused named color; a removed H1 shows as "Not in the template" and can be deleted.

## How to get to it (user POV)

- Write list items under `# 업무` or `# 개인` in a daily note.
- Open **Settings** (gear at the bottom of the left sidebar) → **Sidebar Calendar**: the **Daily note template** line, then **Kinds** with a switch, a round color swatch and a dashed `+` per kind. Clicking the swatch opens the dots; clicking `+` opens the system color picker.
- Edit the template file named in core **Daily notes** settings.

## Gotchas

- Settings opens in its own window in Obsidian 1.14. Without `--settings`, selectors look in the main window and time out.
- The settings tab re-reads the template when it opens, not while it stays open. Switch to another tab and back to see a template edit there; the calendar itself follows the edit without that.
- The native color dialog cannot be driven over CDP. The `+` step proves the click reached the hidden `input[type=color]` and then sets its value and dispatches `input` and `change`, which is what the dialog does when the user picks; report it that way, not as a dialog interaction.
- Escape with the popover open closes only the popover. Escape with it closed closes Settings, as before.
- The popover sits over the next row. If it is still open, a click meant for that row lands on a dot instead.
- Kinds are matched by exact H1 text. `# 업무 ` and `# 업무` are the same kind (trimmed); `# Work` and `# work` are not.
