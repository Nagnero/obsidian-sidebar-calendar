# Sidebar Calendar 구현 계획

**진행 상황 (2026-10-27):** 1~8단계가 `main`에 들어가 있습니다. 남은 일은 9단계(일정 추가)와 커뮤니티 플러그인 배포입니다. 작업 방식은 [CLAUDE.md](../CLAUDE.md)의 pstack 절을 따릅니다.

이 문서는 전체 구조와 단계별 계획입니다. 4절의 2단계 세부 계획은 완료된 기록으로 남겨 둡니다.

## 1. 핵심 원칙

- **계산과 그리기를 분리**합니다. 날짜 계산, frontmatter 해석, 막대 배치는 Obsidian API를 전혀 모르는 순수 함수로 만들고 테스트합니다. 화면 코드는 그 결과를 DOM으로 옮기기만 합니다.
- **날짜는 시간대 없는 `YYYY-MM-DD` 문자열(`DayKey`)로 다룹니다.** `Date`의 시간대 때문에 하루가 밀리는 버그를 막기 위해서입니다. 내부 계산은 UTC 기준으로만 하고, moment 같은 외부 라이브러리는 쓰지 않습니다.
- **화면은 상태가 바뀔 때마다 통째로 다시 그립니다.** 사이드바 달력은 칸이 최대 42개라 충분히 빠르고, 코드가 단순해집니다.

## 2. 파일 구조 (8단계 완료 시점)

```
src/
  main.ts              플러그인 수명주기: 뷰·명령·설정 등록, (8단계) vault 이벤트 연결
  constants.ts         뷰 타입 id 등 상수
  settings.ts          설정 화면
  settingsData.ts      설정 타입, 기본값, 저장값 검증 sanitizeSettings (8단계, 순수 함수)
  types.ts             CalendarEvent 등 공용 타입
  date/
    dayKey.ts          DayKey 파싱·검증, 날짜 더하기, 두 날짜 사이 일수, 오늘
    monthGrid.ts       "이 달을 몇 주로, 어느 날짜부터" 계산 (2단계)
  data/
    parseEvent.ts      frontmatter → CalendarEvent | 오류 사유 (3단계, 순수 함수)
    EventStore.ts      일정 폴더 스캔, 캐시, 같은 경고 반복 방지 (3단계, 8단계)
    DailyNotes.ts      기본 '일일 노트' 설정으로 노트 찾기·열기·만들기 (7단계)
    dailyNotePath.ts   일일 노트 경로·템플릿 치환 (7단계, 순수 함수)
  layout/
    weekLayout.ts      주 단위 분할 + lane 배치 + 넘친 개수 계산 (5단계, 순수 함수)
  ui/
    CalendarView.ts    ItemView. 보고 있는 달, 선택한 날짜 상태를 들고 다시 그리기 호출
    renderMonth.ts     헤더, 요일 줄, 주 줄(날짜 칸 + 막대) DOM 생성
    renderDayList.ts   선택한 날짜의 일정 목록 (7단계)
tests/
  *.test.ts            node:test + tsx로 실행 (`npm test`)
```

데이터 흐름:

```
일정 노트들 ─(EventStore + parseEvent)→ CalendarEvent[]
보고 있는 달 ─(monthGrid)→ 주 목록
CalendarEvent[] + 주 목록 ─(weekLayout)→ 주별 막대 위치, +N 개수
                                       └→ renderMonth가 DOM으로 그림
```

### 공용 타입 (미리 확정)

```ts
type DayKey = string; // 'YYYY-MM-DD'

interface CalendarEvent {
  id: string;         // 노트 경로. 클릭 시 열 때 사용
  title: string;      // frontmatter title, 없으면 파일 이름
  start: DayKey;
  end: DayKey;        // 하루짜리면 start와 같음 (포함 범위)
  category?: string;
}
```

### 나중 기능을 위한 자리 (지금은 구현 안 함)

- **반복 일정**: `EventStore`가 노트를 읽어 `CalendarEvent[]`를 만들 때 펼쳐 넣으면 됩니다. 레이아웃과 화면은 바뀌지 않습니다.
- **한국 공휴일**: 날짜 칸을 그릴 때 `DayKey → 표시 정보`를 돌려주는 함수를 받을 수 있게 칸 그리기를 한 함수로 모아 둡니다.

## 3. 설정 항목과 단계

| 설정 | 기본값 | 들어가는 단계 |
|---|---|---|
| 일정 폴더 | `Events` | 1단계 (완료) |
| 주 시작 요일 | 일요일 | **2단계** |
| 한 주 최대 막대 줄 수 | 3 | 5단계 |
| 기본 색상 | Obsidian 강조색 | 6단계 |
| 카테고리 목록 (이름 + 색) | 비어 있음 | 6단계 |

"최대 줄 수 3"은 **막대 3줄을 그리고 넘치는 일정은 날짜 칸에 `+N`으로 따로 표시**하는 뜻으로 구현합니다.

## 4. 2단계 세부 계획: 월간 달력 + 월 이동 + 주 시작 요일

### 화면 구성

```
┌──────────────────────────────┐
│ 2026년 10월        ‹  오늘  › │  헤더
├──────────────────────────────┤
│ 일  월  화  수  목  금  토     │  요일 줄 (주 시작 요일에 따라 순서 변경)
│ 28  29  30   1   2   3   4    │  주 줄 × 4~6
│  5   6   7   8   9  10  11    │
│ ...                           │
└──────────────────────────────┘
```

- 제목은 앱 언어에 맞춰 표시합니다 (한국어면 "2026년 10월"). 요일 이름도 같은 방식입니다. 브라우저 내장 `Intl.DateTimeFormat`을 쓰므로 의존성이 늘지 않습니다.
- 버튼: `‹` 이전 달, `오늘` 이번 달로 돌아가기, `›` 다음 달. 아이콘은 Obsidian 내장 아이콘(`setIcon`)을 씁니다.
- 항상 **6주**를 그립니다. 첫 줄은 1일이 있는 주이고, 남는 칸은 다음 달 날짜를 흐리게 채웁니다. 주마다 막대 3줄과 `+N` 자리를 항상 확보해 달력 높이가 바뀌지 않습니다.
- 이전·다음 달 날짜는 흐리게, 오늘은 강조색 원으로 표시합니다. 일요일·토요일 글자색 구분은 공휴일 기능과 함께 나중에 넣습니다.
- 주 시작 요일 설정을 바꾸면 열려 있는 달력이 바로 다시 그려집니다.
- 보고 있는 달은 Obsidian을 다시 열면 이번 달로 돌아갑니다.

### 주 줄의 DOM 구조 (5단계 막대를 미리 고려)

각 주는 7열 CSS Grid 하나입니다.
- 날짜 칸 7개는 1행부터 마지막 행까지 세로로 길게 차지합니다 (배경, 오늘 표시, 클릭 대상).
- 1행에 날짜 숫자, 2행부터 lane마다 한 행씩 막대가 들어갑니다. 막대는 `grid-column: 시작열 / 끝열+1`로 놓기만 하면 칸을 가로질러 이어집니다.
- 마지막 행은 `+N` 표시용입니다.

2단계에서는 날짜 숫자 행만 있고, 막대 행은 비어 있습니다.

### 순수 함수와 테스트

- `date/dayKey.ts`: `parseDayKey`(형식과 실제 존재하는 날짜인지 검사, 예: 2026-02-30 거부), `addDays`, `diffDays`, `dayOfWeek`, `todayKey`.
- `date/monthGrid.ts`: `buildMonthGrid(year, month, weekStart)` → `DayKey[][]` (주마다 7일).
- 테스트 (`tests/`):
  - 2026년 10월, 일요일 시작이면 첫 칸이 9/27이고 5주인지
  - 월요일 시작이면 첫 칸이 9/28인지
  - 2026년 2월(28일, 일요일 시작)이 정확히 4주인지
  - 6주가 필요한 달 (예: 2026년 8월, 일요일 시작)
  - 윤년 2028년 2월 29일, 연도 경계(12월 → 1월)
- 테스트 도구는 Node 내장 `node:test`와 `tsx` 하나만 추가합니다. GitHub 자동 빌드에도 `npm test`를 추가합니다.

### Obsidian에서 확인할 것 (2단계 완료 후)

1. 사이드바에 이번 달 달력이 보이고 오늘 날짜가 강조됨
2. `‹` `›`로 달이 바뀌고, 연도 경계(12월 ↔ 1월)도 자연스러움
3. `오늘`을 누르면 이번 달로 돌아옴
4. 설정에서 주 시작 요일을 월요일로 바꾸면 요일 줄과 날짜 배치가 바로 바뀜
5. 라이트·다크 테마 둘 다에서 글자와 강조색이 잘 보임
