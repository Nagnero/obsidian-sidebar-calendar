# Sidebar Calendar

[English](README.md)

일일 노트에 적은 일정을 옵시디언 사이드바의 월간 Calendar로 보여주는 플러그인입니다. 여러 날에 걸친 일정은 날짜를 가로지르는 색 막대로 그려지고, 그날의 할 일은 Calendar 아래 목록에 표시됩니다.

노트는 평범한 마크다운 그대로입니다. 플러그인은 일일 노트 템플릿의 제목 아래에 적은 목록 항목을 읽고, Calendar에서 한 일(추가, 이동, 체크, 기간 변경)은 모두 그 줄에 다시 기록합니다.

![일일 노트와 Calendar를 나란히 띄운 화면](docs/images/overview.png)

> **베타 버전입니다.** 0.1 버전이며, 옵시디언 1.14로 윈도우와 리눅스 데스크톱에서 확인했습니다. 지금은 데스크톱에서만 동작합니다. 문제가 있으면 [이슈](https://github.com/Nagnero/obsidian-sidebar-calendar/issues)에 남겨 주세요.

## 기능

- 여러 날 일정을 제목이 들어간 막대로 표시합니다. 종류별 색상을 쓰고, 라이트와 다크 테마를 모두 지원합니다.
- 일정과 할 일을 나눕니다. 일정은 Calendar에 그려지고, `## To do` 소제목 아래의 할 일은 그날 목록에만 표시됩니다.
- 여러 날을 드래그하거나 날짜를 더블클릭해서 일정을 추가합니다.
- 막대나 목록 항목을 다른 날짜로 끌어서 옮깁니다. 다른 달로도 옮길 수 있습니다.
- 막대 끝을 끌거나 우클릭 메뉴에서 기간을 바꿉니다.
- Calendar 아래 목록에서 바로 체크합니다. 여러 날 일정은 기간 중 어느 날에서든 체크할 수 있습니다.
- 오늘을 선택하면 지난 날짜의 안 끝낸 할 일을 보여주고, 버튼 하나로 오늘로 옮길 수 있습니다.
- 일일 노트가 있는 날에는 점을, 안 끝낸 할 일이 있으면 빈 원을 표시합니다.
- 한 주씩 스크롤하고, 사이드바가 짧으면 한 주만 보여줍니다.
- 설정 화면을 영어 또는 한국어로 볼 수 있습니다.

## 필요한 것

- 옵시디언 1.7.2 이상, 데스크톱
- 코어 플러그인 **일일 노트**를 켜고 템플릿을 지정해야 합니다.

## 설치

### 베타 기간에는 BRAT으로

1. 커뮤니티 플러그인에서 [BRAT](https://github.com/TfTHacker/obsidian42-brat)을 설치하고 켭니다.
2. 명령어 **BRAT: Add a beta plugin for testing**을 실행하고 `Nagnero/obsidian-sidebar-calendar`를 입력합니다.
3. **설정 → 커뮤니티 플러그인**에서 **Sidebar Calendar**를 켭니다.

새 버전이 나오면 BRAT이 업데이트해 줍니다.

### 직접 설치

1. [최신 릴리스](https://github.com/Nagnero/obsidian-sidebar-calendar/releases/latest)에서 `main.js`, `manifest.json`, `styles.css`를 내려받습니다.
2. `<볼트>/.obsidian/plugins/sidebar-calendar/` 폴더에 넣습니다.
3. 옵시디언을 다시 불러오고 **설정 → 커뮤니티 플러그인**에서 **Sidebar Calendar**를 켭니다.

### 커뮤니티 플러그인에서

아직 등록되지 않았습니다. 등록되면 **설정 → 커뮤니티 플러그인 → 탐색**에서 **Sidebar Calendar**를 검색하면 됩니다.

## 시작하기

### 1. 템플릿 준비

Calendar는 일일 노트 템플릿의 최상위 제목(`#`)을 일정의 **종류**로 씁니다. 예를 들어 템플릿이 이렇다면:

```markdown
# 업무

# 개인

# 일기
```

`업무`, `개인`, `일기`가 종류가 됩니다. **설정 → Sidebar Calendar**에서 종류마다 색을 고르고, `일기`처럼 일정이 아닌 제목은 꺼 둡니다.

### 2. 일일 노트에 일정 적기

종류 제목 바로 아래의 체크박스 항목 하나가 일정 하나이고, 그 노트의 날짜에 시작합니다.

```markdown
# 업무
- [ ] 10시 디자인 리뷰
- [ ] 부산 출장 ~10-23
  - 숙소 예약 완료
## To do
- [ ] PR 리뷰하기

# 개인
- [x] 19시 친구와 저녁
```

- **일정**은 종류 제목 바로 아래의 체크박스 항목입니다. Calendar에 막대로 그려집니다.
- **할 일**은 `## To do` 소제목 아래의 체크박스 항목입니다. 그날 안에 끝낼 일이라서 Calendar 아래 목록에만 표시되고 막대로는 그려지지 않습니다.
- 줄 끝에 `~10-23`, `~10/23`, `~2026-10-23`을 붙이면 그날까지 이어지는 일정이 됩니다.
- 제목 앞에 시간(`9:30`, `14:00`, `18시`, `오후 3시`, `3pm`)을 적으면 그날 목록이 시간 순서로 정렬됩니다.
- 들여쓴 줄은 일정에 대한 메모로 보고 읽지 않습니다.
- 체크박스가 있는 항목(`- [ ]`, `- [x]`)만 일정으로 읽습니다. **체크박스 없는 항목도 표시**를 켜면 일반 목록 항목도 일정으로 읽습니다.

한 구역은 `#` 제목부터 다음 `#` 제목 전까지입니다. 그래서 `## 오후` 같은 더 깊은 제목도 같은 구역에 속합니다. `## To do` 구역은 같은 수준이나 더 높은 수준의 다음 제목에서 끝납니다.

## 사용법

리본 아이콘이나 명령어 **Sidebar Calendar: Open calendar**로 엽니다.

| 이렇게 하면 | 이렇게 됩니다 |
| --- | --- |
| 날짜 클릭 | Calendar 아래에 그날의 일정, 할 일, (오늘이면) 지난 할 일이 나오고, 일일 노트가 있으면 열립니다 |
| 여러 날 드래그 또는 날짜 더블클릭 | 일정을 추가합니다. 종류와 **Event**(일정) 또는 **To do**(할 일)를 고릅니다 |
| 막대나 목록 항목을 날짜로 끌기 | 그날로 옮깁니다. 끄는 중에 Calendar 위에서 휠을 굴리면 다른 주로 갈 수 있고, Esc로 취소합니다 |
| 막대 오른쪽 끝 끌기 | 일정이 끝나는 날을 바꿉니다 |
| 할 일의 동그라미 클릭, 또는 목록 항목 더블클릭 | 체크하거나 해제합니다 |
| 막대나 목록 항목 클릭 | 그 줄에서 일일 노트를 엽니다 |
| 막대, 목록 항목, 일일 노트의 일정 줄 우클릭 | **Change duration…**(일정만), **Move to date…** |
| Calendar 위에서 휠 | 한 주씩 넘깁니다. 위쪽 월 표시는 맨 윗줄의 달을 따릅니다 |

![일정 추가](docs/images/add.png)

![끌어서 옮기기](docs/images/move.png)

오늘을 선택하면 **지난 할 일**에 이전 날짜의 안 끝낸 할 일이 나옵니다. 옆의 화살표를 누르면 오늘로 옮겨집니다.

목록 머리의 오른쪽 버튼으로 목록을 정렬(**Start date**, **Note order**, **Unchecked first**, **Kind**)하거나 완료한 항목을 숨길 수 있습니다.

사이드바가 짧아서 한 달과 목록을 함께 보여줄 수 없으면, Calendar는 한 주만 보여주고 목록은 따로 스크롤됩니다.

| --- | --- |
| ![라이트 테마](docs/images/calendar-light.png) | ![다크 테마](docs/images/calendar-dark.png) |

## 설정

설정 화면은 **언어 (Language)**에서 한국어로 바꿀 수 있습니다.

| 설정 | 하는 일 |
| --- | --- |
| **언어 (Language)** | 설정 화면과 목록 묶음 이름을 영어 또는 한국어로 표시합니다 |
| **종류** | 템플릿 제목마다 종류로 쓸지와 색상을 정합니다 |
| **주 시작 요일** | 일요일 또는 월요일 |
| **주당 일정 수** | 한 주에 보여줄 막대 수입니다. 넘치는 일정은 `+N`으로 표시됩니다 |
| **막대 모양** | **제목**은 제목이 들어간 막대, **선**은 얇은 막대입니다 |
| **하루짜리 일정 표시** | 끄면 여러 날 일정만 Calendar에 그립니다 |
| **Calendar에서 숨길 소제목** | 할 일을 적는 소제목 이름입니다. 기본값은 `To do`입니다 |
| **체크박스 없는 항목도 표시** | 일반 목록 항목도 일정으로 읽습니다 |
| **지난 할 일 표시** | 오늘을 선택했을 때 지난 날짜의 안 끝낸 할 일을 보여줍니다 |
| **일일 노트** | 노트가 있는 날에 점과 빈 원을 표시합니다 |

## 알아두면 좋은 점

- 열려 있는 노트는 편집기를 통해 바뀌므로 그 편집기에서 되돌릴 수 있습니다. 일정을 옮기면 노트 두 개가 바뀌므로 각각 되돌려야 합니다.
- 노트가 없는 날짜에 일정을 추가하거나 옮기면 템플릿으로 노트를 새로 만듭니다.
- 이 플러그인은 일일 노트만 읽고 씁니다. 다른 캘린더와 동기화하지 않습니다.

## 개발

1. 이 저장소를 `<볼트>/.obsidian/plugins/sidebar-calendar`에 클론합니다.
2. `npm install` (Node 20 이상)
3. `npm run dev`는 바뀔 때마다 `main.js`를 다시 빌드하고, `npm run build`는 배포용 빌드를 만듭니다.
4. `npm test`와 `npm run lint`로 테스트와 린트를 실행합니다.
5. 옵시디언을 다시 불러오고 **설정 → 커뮤니티 플러그인**에서 **Sidebar Calendar**를 켭니다.

`.claude/skills/verify-sidebar-calendar/scripts/readme-shots.sh`를 실행하면 예시 볼트로 `docs/images`의 화면 캡처를 다시 만듭니다.
